# ssabree_policy

「싸브리타임」의 개인정보 처리방침 페이지다.
싸브리타임은 SSAFY 교육생 커뮤니티 앱이다.

- 페이지 https://simonjiho.github.io/ssabree_policy/
- 앱 https://apps.apple.com/kr/app/id6758888945

## 구성

`index.html` 하나다. 스타일은 파일 안에 들어 있고 스크립트는 없다. 기기가 다크 모드면 어두운 색으로 바뀐다.

문서는 제1조(개인정보의 처리 목적)부터 제13조(개인정보 처리방침의 변경)까지 13개 조다.
시행일은 2026년 2월 8일이다.

## 배포

GitHub Pages가 `main` 브랜치의 루트를 그대로 내보낸다.
`index.html`을 고쳐 `main`에 올리면 페이지에 반영된다.
